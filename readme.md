# 🏦 银行对账技能

把银行导出的流水和公司自己记的银行日记账交给助手，就能核对同一个账户。助手会找出两边哪些交易对得上、哪里有差额，并按账户生成 Excel 报告。每条记录都能追查到原文件、工作表和行号。

## 🧩 哪些助手可以用

这项技能可用于支持加载技能、读取本机文件和运行本机命令的助手。电脑需要安装 Python 3.11 或更新版本，助手会检查运行所需的依赖。

下载完整的[银行对账技能文件夹](.agents/skills/bank-reconciliation-agent)，按你使用的助手的安装方式导入。安装好后，在对话里选用「银行对账技能」，或直接告诉助手使用 bank-reconciliation-agent。

## 📂 准备什么，怎么开始

1. **只核对一个账户**。提供该账户的一份银行流水和一份公司银行日记账。可以用 Excel 工作簿（文件名以 .xlsx 结尾），也可以用逗号分隔的表格（文件名以 .csv 结尾）。
2. **一次核对多个账户**。把银行流水放在一个文件夹，把日记账放在另一个文件夹。在对话里告诉助手两个文件夹的位置，由它按账户找到对应的两份表。
3. **有自己的要求就一起说明**。比如两边的交易日期最多可差几天、用哪两个金额衡量差异大小、报告想存在哪里。日期默认最多相差 31 天，两档差异金额默认是 5,000 元和 100,000 元。项目有自己的要求时，采用你指定的设置。

直接对助手说就可以。

> 请用银行对账技能核对这两份表。两边的记账日期最多可差 3 天。把 Excel 报告放到我指定的文件夹。

## 🔍 助手会怎么对账

1. **先读懂两份表。** 助手看表头和实际内容，找出账户、交易日期、收款、付款、余额等信息。一个文件里有几张交易明细页，就把这些页一起读入。
2. **再找对应的交易。** 同一笔钱可能在两边记在不同日期，也可能银行分两笔扣、公司合起来记一笔。助手会比较日期、金额、摘要、对方、编号和余额。比如银行同一天扣了 40 元和 60 元，账上当天记了 100 元，确认用途一致后就可以合起来核对。几组都能凑出同一个金额时，再看原表上哪一组更符合这笔业务。
3. **分别算收入、支出和余额。** 比如银行多收了 100 元、又多付了 100 元，即使余额相同，报告也会把这两个差额分别列出来。原表能确认一段时间内没有收付款时，该段时间的余额沿用上一笔交易后的余额。
4. **把查出的结果写进报告。** 有差额时，列出两边各记了什么、差多少、对应原表的哪几行。某个账户只有一侧有记录时，照样列出这一侧已读到的收支和日期范围，继续核对其他账户。

## 📊 拿到 Excel 后怎么看

先打开「核对总览」确认是哪一个账户、用了哪两份表，再用「月度核对」和「日度核对」找出现差额的月份或日期。

| 工作表 | 打开后能看到什么 |
| --- | --- |
| 核对总览 | 核对的账户、期间、两份原表和结果概况 |
| 月度核对 | 每月的收入、支出、月末余额，以及银行和账上的差额 |
| 日度核对 | 每天的收付款和日末余额。当天有差额时可看到说明 |
| 差异说明 | 已经查出的差额、涉及的交易和可查看明细的链接 |
| 差异明细 | 每项差额具体涉及的记录及其原表位置 |
| 交易明细 | 两边读入的交易，以及哪些记录被对在一起 |

本机可以调用 Excel 时，助手会打开并重算报告。否则会检查工作表和明细跳转。

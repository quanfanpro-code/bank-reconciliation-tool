# 🏦 银行对账技能

把同一个银行账户的**银行流水**和**公司银行日记账**交给助手。它会找出两边哪些交易对得上，哪一边多记了收入或支出，哪一天或哪一个月的余额有差，并为每个账户生成一份 Excel 报告。报告里的交易可以回查到原文件、工作表和行号。

## 📦 第一步　下载技能

1. 点[下载压缩包](https://github.com/quanfanpro-code/bank-reconciliation-tool/archive/refs/heads/master.zip)。在 Windows 的「下载」文件夹里，右键点击下载好的文件，选「全部解压缩」。
2. 打开解压出来的 **bank-reconciliation-tool-master** 文件夹，依次打开 **.agents** 和 **skills**，找到 **bank-reconciliation-agent**。打开它就能看到 **SKILL.md**，这是助手要读的技能说明。安装时用整个 **bank-reconciliation-agent** 文件夹，里面的文件一起带上。

电脑上需要有 **Python 3.11 或更新版本**。这是助手在本机处理表格时用的。开始核对后，助手会检查并补齐所需的运行组件。

## 🧩 第二步　按你用的助手安装

选下面与你的助手对应的一节。先在电脑上选一个存放对账资料的文件夹，后面也用助手打开这个文件夹。

## 📂 第三步　把原表交给助手

### 只核对一个账户

1. 准备**一份银行流水**。这是从银行导出的表，列着这个账户的每笔收款和付款。
2. 准备**一份公司银行日记账**。这是公司账上给同一个银行账户记的收付款明细。比如要核对工行尾号 1234 的账户，就给这一个账户的两份表。
3. 优先用同一段日期的两份表，放进助手打开的对账文件夹。保留原来的表头、查询日期、账号、余额和全部工作表。支持 **Excel 工作簿（.xlsx）** 和**逗号分隔的表格文件（.csv）**。
4. 在对话里把两份文件的名称说清楚。也可以用助手的附件入口直接选中两份表。

> 请用银行对账技能核对「工行1234流水.xlsx」和「工行1234日记账.xlsx」。这两份表都在当前文件夹，报告请放到同一个文件夹。

### 一次核对多个账户

1. 在对账文件夹里建两个文件夹。一个叫「银行流水」，放各账户从银行导出的表。另一个叫「银行日记账」，放公司账上各账户的明细。
2. 在对话里说明哪个文件夹是银行流水、哪个是日记账。助手会按账户找出对应的文件，为各账户分别生成报告。

> 请用银行对账技能批量核对当前文件夹里的「银行流水」和「银行日记账」。每个银行账户生成一份 Excel，统一放到「对账结果」。

助手在开始核对前会先问三件事，没有你的回答不会开工。日期容差默认 31 天，助手会问要不要改；不改就按 31 天找可能对应的交易，改了就按你给的天数。另外要你给出两个金额：明显微小错报临界值，以及实际执行重要性水平。不超过前一个数的异常只留存备查；超过前一个数但不超过后一个数的，先按月累计，累计超过实际执行重要性水平才需要处理；超过实际执行重要性水平的异常会写进差异说明。刚好等于实际执行重要性水平，不算超过。报告默认放在本次任务的文件夹。

## 🔍 助手会怎么对账

1. **先读懂两份表。** 助手看表头和实际内容，找出账户、交易日期、收款、付款、余额等信息。一个文件里有几张交易明细页，就把这些页一起读入。
2. **再找对应的交易。** 同一笔钱可能在两边记在不同日期，也可能银行分两笔扣、公司合起来记一笔。比如银行同一天扣了 40 元和 60 元，账上当天记了 100 元，确认用途一致后就可以合起来核对。几组都能凑出同一个金额时，助手会继续比较日期、摘要、对方、交易编号和余额，从里面选出最符合原表的一组。
3. **分别算收入、支出和余额。** 比如银行多收了 100 元、又多付了 100 元，即使余额相同，报告也会把这两个差额分别列出来。原表能确认一段时间内没有收付款时，该段时间的余额沿用上一笔交易后的余额。
4. **把查出的结果写进报告。** 有差额时，列出两边各记了什么、差多少、对应原表的哪几行。某个账户只有一侧有记录时，照样列出这一侧已读到的收支和日期范围，继续核对其他账户。

## 📊 第四步　打开报告看结果

在助手给出的位置打开该账户的 Excel 文件。窗口底部有六个工作表标签，可按下面的顺序看。

1. **核对总览**。先确认账号、两份原表的文件名和读入的笔数。这里会给出月度核对的总体结果。
2. **月度核对**。看哪一个月出现差额。收入、支出和月末余额各有银行金额、账上金额和差额。如果银行支出是 2,500 元，账上支出是 2,000 元，支出差额 500 元表示银行比账上多付 500 元。
3. **日度核对**。找到当月差额出现在哪一天，再看那天两边的收付、日末余额和「说明」列。
4. **差异说明**。看某项差额涉及什么事、银行和账上分别记了什么、差多少。该项有交易明细时，可点「查看全部…笔」。
5. **差异明细**。看这项差额涉及的每笔记录。要回到原表，就按「原表位置」里的文件、工作表和行号查找。
6. **交易明细**。需要看所有已读入的交易时，打开这张表。核对到一起的银行记录和账上记录用同一个编号列出，可以顺着该编号一起看。

助手交付前会检查报告和明细跳转，并用原表复算收支和余额。能调用本机 Excel 时，也会打开报告重算。

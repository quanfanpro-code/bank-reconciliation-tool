# 采用统一候选、评分与分流中心

银行流水核对现有各阶段会直接占用记录并各自判断置信度，导致后续候选无法公平比较，也无法一致执行重要性水平、明显微小错报、多字段文字和大模型辅助规则。经比较“继续打补丁”“统一候选中心”和“全局最优求解”三种方案，决定保留现有精确匹配、组合求和与汇总算法，但让它们先生成候选，再由统一中心完成评分、冲突消解和状态分流；该选择比继续打补丁更能保证业务口径一致，又避免全局优化器带来的性能、解释性和新增依赖风险。

## 后续影响

- 现有匹配算法可以继续复用，但不得在候选生成阶段直接把记录标记为已确认。
- 综合可信度、两个重要性阈值、自然月四个差异池和大模型语义证据统一在分流中心处理。
- 报告直接读取结构化候选证据，避免重新猜测匹配理由。
- 如果真实数据以后证明确定性冲突消解明显不足，再单独评估全局优化方案。

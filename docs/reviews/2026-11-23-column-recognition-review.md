# 列识别验收

- 在原版本复现列顺序改变导致的错列，覆盖手续费金额、起息日期、可用余额、交易对方账号和对方币种。补测本工具模板里的「账户」列，核实不同账号在首轮匹配前被拦截。
- 桌面程序和 Skill 通过同一个入口读取原表并识别字段。验证列换序、收支分列、单金额列、金额加方向、原币与本位币以及余额变动区分金额候选。只有时分秒的列无法作为交易日期。
- 模拟批量中单户存在两个无法区分的金额候选。程序列出字段和原列名，只暂停该户。传入经确认的列后，只补跑该户并生成标准五表。
- 复跑实际九户，对照原表核对各户笔数、逐日和逐月收支及五张表结构。另走桌面读取和执行入口验证曾把付款方认成本户的一户。实跑中 Windows 禁止启动 Excel，使用报表文件结构、单元格和明细跳转检查。
- 本次相关回归通过 42 项。另对照改动前版本复现了历史报告和匹配测试的既有失败。界面窗口启动测试依赖 Windows 图形会话。

# 银行流水核对 Skill 验收

- 核对范围、复用方案和实施计划分别得到用户确认。所有需要用户作的选择由当前 Agent 提问。文件、参数和问答都不依赖独立模型服务。
- 文件配对、历史报告过滤、重复与缺配、候选答复编号检查和报告回读通过定向测试。已用实际文件分别验证单户与批量入口，五张表和原始收支可以复算。同一账户使用相同参数时，两种入口的五张表一致。
- 批量实跑复现了将交易付款人列误当本方账号的问题。修复位于桌面程序的共用列识别，先独立通过测试、重跑和发布，再验收本 Skill。
- 正式报告仍优先用本机 Excel 打开。验收环境启动 Excel 被拒绝时，实际运行了五表结构、填写区和明细跳转检查，另行回读日期、笔数和金额。该次验收未执行 Excel 自身的重算。
- 项目内 Skill 已通过格式校验。当前会话不能写入个人技能目录，使用项目内入口。

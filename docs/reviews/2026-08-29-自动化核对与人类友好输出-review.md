## 业务场景结果

| 场景 | 程序结果 |
|---|---|
| 唯一一对一、一对多或多对一 | 自动确认 |
| 多套合理拆分但整个交易组完全闭合 | 整组勾稽一致，不虚构逐笔对应 |
| 小额非零差异 | 自动归集事项，按明显微小临界值分级 |
| 单项重大或月度累计超限 | 高风险疑点，程序继续完成 |
| 候选歧义、关键文字冲突或跨期 | 疑点事项，程序继续完成 |
| 账户或币种缺失、混合或双方冲突 | 范围受限提示，程序继续完成 |
| 没有有效余额 | 显示“余额核对未实施”，不从零伪造余额 |
| 双方余额相等 | 不生成余额差异 |

## 残余限制

- 账户和币种范围判断依赖原始文件中存在可识别的本方账号、银行账号、币种或币别列；缺失时程序会标为范围未验证，不会猜测。
- 多解闭合只确认交易组整体，不声称组内每一笔的唯一对应关系。
- 本轮不开发报告回传、宏或数据库；人工后续标注只保存在当前 Excel 文件中。

# 验收：先问设置，再按重要性列出异常

审查范围是 GitHub 上银行对账技能的当前修改。正常记录仍直接确认。差异说明只收超过用户所给实际执行重要性水平的异常，以及有更大异常时抽中的中风险。不超过明显微小错报临界值的留存备查。

已验证：`tests/test_异常优先核对.py` 15 项通过。`tests/test_银行核对入口.py` 中，未提供三项设置时技能入口拒绝启动，该文件其余测试以及 `tests/test_Agent与核对闭环.py` 通过。`tests/test_复核事项分流.py` 有 2 项失败，比较的是仓库根上的旧复核事项，本次没有改那个文件，失败在修改前就已经存在。

残余：助手是否真的先开口问用户，取决于它是否遵守技能说明。程序侧已经不允许省略这三个参数。

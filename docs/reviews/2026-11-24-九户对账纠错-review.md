# 九户银行对账纠错验收

## 对照原表

- 使用正常 Skill 入口重跑九户。同一批原表、日期容差和重要性设置。9 份 Excel 都经本机 Excel 打开并重算，6 个报告内跳转分别落到正确明细。
- 独立对回银行 2,188 行和账上 1,988 行，复算日期、收付、日月汇总和账上月末余额。九户的月表均按明确账期列齐。原文件和对照老报表哈希与原样一致。
- 月底前无收付的已覆盖期间正常结转余额。月表恢复老版以前列对的七户账上期末数。两次输入相同的期间比较金额。老报告另行使用的截图和独立余额表属于不同资料范围。
- 按两侧原行比对，老版有 4,083 行已对上，新版有 4,091 行已对上。老版已对应的原行仍在新版中对应，另外八户的分组保持一致。
- 手续费分回两个原交易日，已对准的其他同日业务仍可分别追查。交易后余额相同的两笔重复金额分别对应。普通差异直接列出两方向的金额和原行。

## 测试

确认范围的五份旧测试已备份并移入 Windows 回收站。新业务验收覆盖错配、不同日期容差、异版式和区间余额。有针对性的测试合计 45 项通过。

代码定稿后另建两份模拟原表。银行流水分两页且换列顺序和字段名，日记账改用以月标明的抬头及累计发生额。两个同日组合各自对上，不同订单的等额收付分别计入差额。该案例使用正式入口生成并回读六张表。

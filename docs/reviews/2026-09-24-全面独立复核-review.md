# 2026-09-24 全面独立复核

## 复核范围

对当前基线（c25191c，含非工作日银行收付示警）做全面独立复核：全量自动测试新鲜运行、关键链路静态审查、独立构造边界用例端到端验证。审查链路覆盖：表头识别与十三项输入检查（input_precheck.py、data_loader.py）、金额方向解释（data_loader.py）、候选生成与整批冲突选择（matcher.py）、评分与重要性分流（matching_policy.py）、复核事项归集与等距抽样（复核事项.py）、人工结果公式与覆盖率（复核报表.py）、八张阅读表（报告展示.py）、筛选导出（底稿筛选.py、筛选窗口.py）、原子交付与公式注入防护（make_excel.py、reporter.py）、大模型脱敏（llm_assistant.py）、非工作日示警（非工作日日历.py 及报告集成）。

matcher.py、reporter.py 等大体量模块按关键链路抽查，未逐行覆盖；GUI 以代码审查和既有自动测试为准，未做人工点击验收。本轮无真实银行流水资料，真实规模验证以构造数据为准，不构成准确率证明。

## 发现与修复

### 缺陷 1：方向列数据值污染表头层级评分（已修复）

- 现象：单层表头、方向列同时含"借""贷"的表格，自动检测把前两行数据误判为表头，派生出"日期（2026-02-15，2026-03-07"式垃圾列名，随后以"未找到日期列"阻止核对。
- 根因：`_keyword_hits` 对候选表头区域整体做子串匹配，关键词组含独立的"借""贷"（input_precheck.py 原 42—43 行）；深层表头候选圈入数据行后，方向列的"借""贷"被计入关键词命中，每组加 1.5 分，而深度惩罚每级仅 0.1 分，混合方向时 3 行表头候选得分 11.3 反超单层表头的 11.0。
- 影响面：方向值出现在数据区前几行且表头关键词较少的简单表格；规范多级表头文件因表头自身关键词多，不易被反超（此前 2,509 行真实流水验证通过亦印证）。
- 修复：`_keyword_hits` 统计前剔除精确等于"借""贷"的单元格（input_precheck.py）。单字"借""贷"几乎不构成正式表头列名，真实表头常写的"借方""贷方""收入""支出"均不精确等于单字，不受影响；"收入""支出"因可能是真实表头列名（收支两列式），不在剔除范围，属于已记录的权衡。
- 回归防护：新增定向测试证明混合方向单层表头识别为 1 行表头、真实两级表头仍识别为 2 行；端到端场景覆盖修复前被阻止的完整核对流程。

### 复核中确认为设计行为、未修改的事项

- 金额口径未注明时（通用金额列、无 amount_basis 声明），总体资料按设计标为范围受限，全部单边记录按范围未知进入人工全查。构造场景曾因此出现"全查 8 项"，与 CONTEXT.md"金额口径"词条一致，不是缺陷；补充口径声明后分级恢复为中风险抽样、高风险全查。
- "中风险抽样总数/中风险抽中待核查数"由复核报表以复核事项索引为准写入活公式，matcher 候选级静态统计在正式报告中总是被覆盖，不存在两个口径并排展示。
- 覆盖比例筛选：校验层接受 0—1 小数，GUI 已把用户填写的百分数除以 100，错误文案"0到100之间"面向填写者口径，一致。

## 审查确认无问题的关键点

- 非工作日日历 2021—2026 年放假区间与调休补班日逐项核对，与国务院办公厅通知一致；2026 年安排经[国办发明电〔2025〕7号](http://sjt.guizhou.gov.cn/zwgk/zdlyxx/xwfb/202511/t20251107_88922639.html)原文复核。示警只取银行有效非零收付，补班日、工作日、零金额不列入，越界年份单列未覆盖笔数，与序时账日期和匹配状态无关。
- 候选选择：并查集按共享源行分组，小组穷举最优不重叠组合，大组与中止时稳定降级为贪心，诊断披露完整。
- 重要性分流与 README 第一节一致：刚好等于实际执行重要性水平为中风险，超过才为高风险；明显微小自动确认要求零差额、组金额不超过临界值且无硬冲突；中风险等距抽样样本数为中风险事项数与高风险事项数的较小值，范围未知不计入基数。
- 人工结果承接：复核事项统计为活公式（COUNTIF/COUNTIFS），已对平覆盖率只计有效且零差额关系；原子交付先写临时文件再改名，拒绝覆盖同名报告和原始输入；全部外来文字经 clean_excel_string 防公式注入。
- 大模型脱敏：密钥替换、路径隐藏、账号卡号与 8 位以上数字掩码、Bearer 掩码、URL 只保留服务位置；未启用时不进入核对流程。

## 残余风险与使用边界

- "收入""支出"等双字方向值仍参与表头关键词命中；极端弱表头且方向列使用"收入/支出"标注时，理论上仍存在深层表头反超可能，但这类词同时是常见真实表头，剔除代价更高，本轮保留现状并在此披露。
- 本轮未做真实流水端到端验证；2027 年起需补充当年官方日历后示警功能才覆盖该年度。
- 桌面既有 EXE 不随本次源码提交更新。

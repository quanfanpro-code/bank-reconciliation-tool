# 筛选交互易用性验收

用户明确要求修正上轮列出的三处不足：文字条件不用分号录入、选择报告后自动加载选项、列顺序支持拖动。本轮以80d1b2a为基础，沿用源码、README、提交推送授权；无打包、安装、桌面EXE操作，无匹配算法、重要性或抽样规则变更。

## 实际改进

1. 文字和结果条件改为清单，逐条添加、修改、移除。输入标点按原文保留；重复条件不重复加入；未加入清单的草稿在预览或导出时明确提示。包含全部满足、排除任一出现、其他同类任一满足的原规则在窗口始终可见。
2. 窗口直接选择或更换报告，后台自动读取实际类型与结果选项。改条件预览复用当前数据；换报告清空旧条件，同一报告修改后重新读取。单个后台线程依次处理，快速换文件只保留最新待办，旧结果不能写入新报告的界面。失败可重新选择，关闭窗口后后台不再引用窗口对象。
3. 列名可以拖动，保留上下移按钮和Alt+上下键；保存重开保持顺序，全部列保留。调整仍仅适用于以后生成报告，人工填写及旧报告不搬列。
4. 多条长条件使用可滚动清单与摘要，底部操作按钮固定保留；小窗口也不挤掉导出和取消。

# 核对逻辑设计

在 Skill 私有的入口补充逐笔、余额和异常步骤。程序提供入口参数和复用点，保留原有匹配入口。只改呈现会保留错误判断，另写核对器会丢掉原来的组合搜索和报告定位。复用原程序的读表、余额链、递归剪枝和候选占用，使使用同一份五表报告。

先验证同一账户及列映射。从完整容差窗口确认唯一的一对一关系，并保留已验证的余额依据。余额链以能闭合的局部区间为准，断点后重新起算。剩余数据继续生成合笔和特殊业务候选。只有能够由互不重叠的实际候选覆盖全部记录的组合才能用整组结论。纯总额供日月比较。收入和支出分别计算。

匹配完成以后才列待查。收付差值按实际差额分级。真实冲突或候选会留下不同记录时，按受影响金额分级并标明原始行。整月某一侧无逐笔，只列受影响月份。Agent 读取两张表的原文，判断细化用途是否矛盾并比较仍合理的候选。明确的用途冲突须核验双方引用。超时单独记录，匹配继续完成。

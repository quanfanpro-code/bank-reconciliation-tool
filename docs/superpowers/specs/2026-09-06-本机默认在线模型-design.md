# 本机默认在线模型设计

采用本机配置文件，复用LocalProjectStore确定的应用目录和build_llm_config校验，GUI初始化加载；应用接口的LLMConfig默认值及匹配算法保持原样。

备选一是在源码硬编码个人连接与密钥，会把个人接入传播至仓库，不采用。备选二是用户环境变量，只能覆盖原有密钥读取，GUI地址和开关仍需额外改造。采用现有本机应用目录中的大模型默认配置.json，配置集中且下次启动立即读取，无新增配置系统。

文件仅由本次配置任务写入，GUI现有“保存当前会话配置”仍只影响当前运行；不擅自增加自动持久化所有操作的行为。主界面启动和手动改配置后共用状态刷新，显示实际启用状态、模式和模型。

配置错误统一给出不包含原文的提示；不存在配置时保持旧默认关闭。启用配置沿用原校验，超时上限由300扩大到600秒以接受服务文档建议。不涉及候选筛选、金额计算或模型评分规则。

以真实GUI和受控临时配置验证正常、关闭和异常；在线验证只发构造数据。无业务术语变更，不修改CONTEXT；此配置可逆，无须新增ADR。

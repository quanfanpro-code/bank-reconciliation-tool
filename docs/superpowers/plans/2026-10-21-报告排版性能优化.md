# 报告排版性能优化 实施计划

> **For agentic workers:** 本计划由主会话按 `executing-plans.md` 串行执行（用户已授权自主完成后续步骤；不使用子代理）。步骤用 `- [ ]` 跟踪。

**Goal:** 把核对报告排版从"写后读回、五遍逐格修改、整体重存"（30 万行 7 小时+）改为"排版前置计算、单次写入一次成型"，大账户出报告 ≤ 5 分钟，效果逐格一致。

**Tech Stack:** Python 3.14、pandas、openpyxl 3.1.5（普通模式，不换库、不加依赖）、pytest。

**Spec:** `docs/superpowers/specs/2026-10-21-报告排版性能优化-design.md`；需求：`docs/requirements/2026-10-21-报告排版性能优化-requirement.md`

# 非工作日银行收付示警 Implementation Plan

> **For agentic workers:** Read `subagent-driven-development.md` when the user authorizes subagents; otherwise read `executing-plans.md` and implement task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 对 2021—2026 年的银行侧有效收付款逐笔识别全国统一非工作日并在报告中示警。

**Architecture:** 新增独立日历模块保存官方放假区间和补班日。报告器只扫描银行侧有效明细并产生示警表与首页汇总；现有报告展示层使工作表可见，不改匹配与人工核对。

**Tech Stack:** Windows、Python 3.14、标准日期库、现有 pandas/openpyxl/pytest。

**Spec:** `docs/superpowers/specs/2026-09-24-非工作日银行收付示警-design.md`

## Global Constraints

- 只读输入银行流水与序时账；只按银行侧日期识别。
- 日历覆盖 2021—2026 年，官方通知为准，运行不联网、不新增依赖。
- 超出年份标为未覆盖；示警不改变现有风险分级和匹配结果。
- 修改已有文件前备份并校验；中文文本使用 UTF-8。

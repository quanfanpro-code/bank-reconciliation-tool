# 人工核查改为疑点提示与自由留痕

## 已确认需求

用户指出：程序只能列出有限候选，不能要求核查人员从“采用其他对应1、2”等清单中挑配对。程序负责警示，并让核查人员方便查看原始记录；人工只记录核查结论和备注，可以留空。

2026年10月22日，用户确认“开工”，授权按上述方向修改原程序、更新说明、提交推送并将新报告放桌面。沿用本项目已确认的需求优先流程，本轮需求、方案与执行顺序沿用已向用户说明并获批准的结论，不重复要求确认。

## 范围与约束

- 取消人工配对下拉，核查结论与备注均自由输入。
- 保留程序疑点、双方完整组成、原始文件及行号、参考候选和返回填写入口。
- 参考候选未穷尽所有可能，不能当成全部真实交易或要求用户采用。
- 填写仅更新结论记录数量，不改变程序配对、疑点、金额、期间、月度差额、覆盖率。
- 保留已有真实填写，不把旧程序回显公式作为人工输入。
- 不改变匹配算法、重要性、日期窗口或原始资料；不重新运行模型。
- 既有文件先备份，新报告另取文件名，不覆盖用户已填写的旧报告。

## 验收

1. 新报告黄色核查结论及备注格无配对下拉和输入选项限制。
2. 任意正常核查文字可记录；清空或只填空格仍列为未记录结论。仅有备注也不作为结论完成。
3. 填写前后配对、原始交易金额、已对平比例、月度差额不变；自动确认关系不受影响。
4. 排序后按稳定事项编号回显，不串事项；证据与参考线索跳转有效。
5. 本次真实资料银行、序时账各2012笔，事项证据5823行，1799个核查事项；收入及支出原值不变。

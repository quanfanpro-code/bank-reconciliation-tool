# 消除搜索造成的假异常、空输入假成功和手续费总览误报

技能仍只自动发现异常，不把每笔都交给人去对。两档重要性、月度累计和原有抽样继续决定哪些异常写入差异说明。

已确认要修的三件事：

- 同一天、同一收支方向，一边一笔金额正好等于另一边全部明细相加，而且少任意一笔都会对不上时，程序直接整组确认。不能因为搜索只看了前 30 笔，就把这一组拆成许多假异常。
- 两个空目录、没有任何可核对账户时，退出码不能是成功，并写明没有发现可核对的账户或支持的输入文件。不生成正式报告。
- 手续费净额已经说明的，先从月度未解释差额里剔除，再写总览。总览不能再说这个月有收支差额。

不新增人工选择、人工确认或额外提问。

# 本机默认在线模型需求

用户明确要求使用指定在线API与新提供密钥，并让GUI默认启用。用户消息中的密钥优先于接入文档中的旧密钥；文档仅提供地址、模型和协议事实。

## 范围及验收

- 当前电脑启动GUI自动加载本机默认配置，启用Qwen3.8-27B在线辅助；对话框预填连接参数和密钥，仍能在当前会话关闭或更换。
- 复用既有模型客户端、字段规则、失败降级、匹配评分和人工核对规则；本轮只修改GUI配置入口及连接超时校验。
- 使用现有本机应用目录保存默认连接，个人密钥不放入仓库、README、日志或报告；个人服务地址不硬编码或提交到仓库。原报告记录服务地址的行为不变。
- 服务文档建议长请求等待600秒，因此本机默认超时600秒；候选上限沿用5。
- 本机配置不存在时维持关闭；损坏或不合法时GUI仍可打开，日志提示重新配置且不输出配置原文或密钥。
- 验证真实GUI默认值及对话框、手动关闭、再次启动、异常配置、真实API连接与构造候选请求、完整回归及源码入口。

本次需求、使用方式和服务选择均由用户明确指定，无待确认项。沿用本对话已授权的README更新、提交推送，在master上完成；不新建分支。无新增依赖，不重建独立EXE。

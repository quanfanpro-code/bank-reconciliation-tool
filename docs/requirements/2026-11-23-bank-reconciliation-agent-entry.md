# 银行流水核对 Skill 需求

用户已确认单户和批量两个入口。单户输入为银行流水和银行日记账。批量从两个目录按公司、银行和完整账号配对。报告和模板跳过。账户重复、缺配或处理失败时保留该户的问题，其余账户继续。

用户交互统一通过提问完成。只问本次缺少的输入、两项重要性金额、报告位置或需要用户决定的文件冲突。已经回答过的信息直接使用。

用户选定复用修复后的核对程序。单户和批量输出相同的核对总览、月度核对、日度核对、待核对和交易明细。保留原始金额、日期和行号。候选文字由运行 Skill 的 Agent 判读，程序检查原始行、金额和方向。不需要额外配置模型 API 或密钥。

验收覆盖单户、实际两个目录、已有历史报告、重复与缺配、Agent 意见的接收与拒绝、五张表复读和原始行数复算。用户已批准实施计划。
